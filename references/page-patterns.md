# 信息关系与页面表达

## 内部规划

先确定每页的主要信息、材料依据、信息关系、主体表达和阅读主次，再制作对象。这些是内部决策，留在工作区，不写进纯上屏文字稿。没有复杂关系时，清楚的文字页也可以成立。

页数、章节和页面构图由本次内容决定，不复用某个项目的固定页序。主要关系明确后再选表达，不把文档段落直接改成等长列表或通栏表格。

每页承载一个可独立理解的内容单元。同一组同类要点能用分组、对照或多行在可读字号下完整展示时，放在同一页，不因为“每页三项”、等宽卡片或留白习惯而拆成两半。规划后检查相邻页，合并仅续列同一组内容的页面。具有独立任务、依据与结论的子主题可分别成页，不能把整章误当作一个必须压缩的页面；内容复杂时按清楚的子主题展开，不按条目数量切割，也不删减限定或缩成小字。

| 信息关系或任务 | 适合的表达 | 关键判断 |
| --- | --- | --- |
| 演示主题 | 简洁封面 | 标题是主体，身份信息来自当前授权 |
| 导航 | 封面后的目录、正文进度栏 | 章名、顺序及跳转目标与实际内容一致，短演示可省略 |
| 同维度逐项比较 | 原生比较表、左右对照 | 对齐比较条件，突出差异 |
| 并列概念或实施条件 | 主题分组、括线或分区 | 不把并列强行画成时间顺序 |
| 输入、判断、行动与反馈 | 机制图、分支或闭环流程 | 动作、触发条件和反馈清楚 |
| 不同角色承担不同职责 | 角色分区或泳道 | 看得见谁决定、谁执行、交接什么 |
| 层级、包含或共同支撑 | 分层、汇聚或资源与目标对应图 | 不把分类包装成因果关系 |
| 数量结果或变化 | 原生数据图表与短解释 | 数值可追溯，单位、分母和时段完整 |
| 模型 | 可编辑公式与变量定义 | 符号、参照条件和解释一致 |
| 工作安排 | 时间轴、阶段或计划图 | 顺序、依赖和里程碑准确 |
| 场景与问题 | 相关图片配具体说明 | 图片解释场景，不充当不存在的证据 |
| 总结与交流 | 简洁结论、感谢或交流页 | 结论有依据，收尾符合场景 |

## 常见取舍

表格适合读者沿相同维度逐项查阅，不因为方便排版就用表格装并列文字。大量单元格变成长段落时，考虑拆分比较重点或改用主题分组；原要求保留的行列和证据不能丢失。

完整流程应先在同一页展示从起点到终点的必要步骤和关键分支，不把前半段、后半段分别放在两页。可用多行、折返或分区组织，保留连续编号与清楚连线；不能为了等宽大卡片而割裂流程，也不能靠缩成小字容纳。

每个步骤嵌入理解所需的动作、责任、输入、判断或输出，不能只剩框标题。确需展开复杂细节时，在完整总览后增加局部详解，不以分段详解替代完整流程。箭头的几何要求见 [视觉规范](design-system.md)。

同一套演示允许不同构图，同类信息可连续采用同构表达；若只是反复替换框内文字，应重新判断关系。不要为了增加版式或图片数量而添加装饰、无关照片或虚构统计图。

## 阶段、证据与结论的对应

阶段性内容可采用横向阶段标题，并将每阶段的关键动作、输入输出及相应证据或示意放在同一列。下方内容应解释这一阶段，不能只在标题下堆积无关图片。材料没有实证图时可用真实关系的定性图解，不补造实验或业绩证据。

角色页或图文页将对象名称、相关图片与职责说明放在同一区域，建立直接对应。照片或示意应帮助理解当前对象，不能只占位。

多方价值页面可把每方对象、对应场景与收益机制组成一组，横向对照或围绕共同主体排列，形成明确图文主次。避免仅将对象名与一段说明分散成多行，留下缺乏作用的大面积空白；不因需要图片而新增未经确认的结论。

有真实层级或逐步深入关系时再采用阶梯构图；并列观点保持平齐，不因模板有阶梯就添加递进箭头。有明确结论或关键限定时，可在相关证据附近集中呈现已确认的原文，不把结论条变成每页重复的固定页脚。

## 证据组织与中心构图

证据充分时可按“证据—解释—结论”安排阅读顺序：同一问题的图表或事实集中成组，旁边说明能支持什么，再以准确的短结论收束。每项结论应有对应依据，不能拼接不同主题的图表、用箭头暗示未经证实的因果，或把预期效果写成实测结果。没有数值或实证图时，使用材料支持的定性解释，不为套版式补造证据。

当核心机制、对象或问题可以成为视觉主体时，可将其置于中心，两侧分别组织相关需求、约束或解释，建立直接对应。两侧不必强行等长，也不把这种构图固定成两个类别；缺乏合适主体时采用其他表达。

长演示允许目录页、证据页、机制页和结论页具有不同密度。目录突出章节结构，证据页给关键图表足够空间，机制页突出关系，结论页保持简洁；不用一套框格排满所有页面。

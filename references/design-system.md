# 可调整的视觉规范

用户指定的品牌、模板与视觉要求优先。以下为无品牌约束时的展示默认值，不代表特定主题或机构。

## 标题与文字层级

页面标题只写主题名称，不采用“标题：内容”形式；补充说明放正文，不改用破折号、竖线或括号继续拼接解释。需要区分同类页面时采用明确的主题名词短语，专有名词内部必要符号保留。

采用环境中已安装且覆盖所需语言的字体，中文可选微软雅黑或同类清晰字体。先确认字体与字号单位，再设置对象。

| 角色 | 建议字号与字重 |
| --- | --- |
| 封面标题 | 44–52 pt，加粗 |
| 内容页标题 | 34–40 pt，加粗 |
| 节点或模块标题 | 26–30 pt，加粗 |
| 主要正文 | 优先 24–28 pt，常规或中等字重 |
| 必要的图内说明 | 优先 22–24 pt |
| 必须展示的来源或导航标签 | 通常 18–20 pt，不承载主要论述 |

保持大字与清楚分区，以字重、颜色和位置建立主次，不把整页正文全部加粗。关键词可局部加粗或变色。内容拥挤时先提炼重复文字、分组或重排，不默认缩小字号，也不将完整流程或同一组要点机械拆页；确有独立子主题时按内容边界分别展开。已确认文字需要改动时遵循审阅流程。按语义断行，避免拆开术语与关键短语。

## 画布、配色与图文

默认 16:9，统一边距、标题基线与同级样式，主体空间由内容关系决定。留白用于分组和聚焦，不能让主体缩在一角、解释散落在空白中。

可采用深蓝封面、白底内容页。以下配色是起点，可随参考或品牌调整：

| 角色 | 建议颜色 |
| --- | --- |
| 封面与结束页 | `#062A7E` |
| 页面标题 | `#0B2E59` |
| 模块与流程 | `#0A48AA`、`#1266B3` |
| 正文 | `#1D2B3A` |
| 主背景与浅色辅助 | `#FFFFFF`、`#F4F9FF`、`#D8ECFF` |
| 关键差异或限定 | `#BC111A` |
| 重点动作或边界 | `#F28C28` |
| 支持条件 | `#2E8B57` |

同一颜色跨页保持相同语义，不机械给每个模块分配新颜色，也不只靠颜色传达差异。

功能模块可采用蓝色标题区、白色说明区、适度圆角与清楚轮廓。依内容穿插括线分组、对照、流程和图文组合，不把整套页面统一替换为浅色矩形框。

阶段标题可以使用箭头形条带，与下方动作和对应证据对齐；图片区、文字区及结论区各有职责。结论或限定可用简洁强调条收束，仅承载已有且需要突出的信息，不增加未经确认的总结句。避免为模仿参考而叠加虚线框、渐变、装饰底线或小字。

相关照片或插画可以成为场景页主体，需与说明共同解释内容。图片保持比例，采用适当裁切，不拉伸；生成插画不能冒充真实场地、人物或设备的证据。封面与结束页可以视觉呼应，但不预置固定建筑、标识或主题图片。

## 功能性箭头

先安排节点，再画连接线，起终点要清楚对应实际对象。线宽、箭头形态与方向跨页一致；线段应有足够长度，不能只剩悬空的箭头尖端，也不能贴住边框或穿过文字。

优先采用整齐的水平、垂直与直角路径，转折保持间距。多路输入先形成清楚的汇合点，再输出一支箭头；区分汇合、分支与反馈，不把线条重叠当作连接。小屏缩放后也应能看清箭头与节点的关系。

## 导航、结束页与备注

多章节完整汇报默认在封面后加入目录页，列出实际章节，计入总页数。可采用大色块配短列表，以字号和编号区分层级，不复制参考中的机构标识、水印或固定章名。单页、短演示或用户明确要求省略时不强加；用户明确要求目录时必须保留。目录名称、正文顺序和章节进度栏保持一致。

多章节完整汇报默认将标题置于页眉左侧、章节进度栏置于右侧，二者同处一条水平页眉带并垂直对齐，正文统一排在其下，不把导航悬在标题上方另起一行。章名和数量由实际内容决定，以主色和形态突出当前章节，其余用中性色弱化；位置、尺寸和章节顺序跨页一致。先分配标题与导航区宽，核对最长标题，不为排下导航压缩正文或遮挡标题。

导航尺寸按章名长度与页眉可用空间分配，不机械沿用参考的宽高。文字两侧可各留约 0.6–0.9 个字宽，保持上下留白均衡；常态与高亮项的文字垂直中心一致，高亮仅适度加高，不靠缩小字号或偏移文字突出。标题与导航之间保留清楚间距，以最长标题、最长章名和实际展示尺寸核对整套页面。

封面、目录、感谢页以及单页或短演示通常不放进度栏，用户要求无导航时省略。完整现场汇报默认在总结后安排简短感谢或交流页，计入总页数；用户明确不要或场景不适合时省略。结束页不新增未提供的身份、联系方式或标识。

默认不加页码、总页数、主题角标、页脚细线和重复性的底部总结。必要来源、单位及限定仍需清楚可见，不能缩成无关小字。

默认所有页面备注栏为空，不写讲稿、来源、素材说明、制作过程或检查记录。用户明确要求备注内容时再填写；必要可见信息放正文，追溯信息留工作区。

## 简洁与视觉主体

简洁不等于只在大片留白中散放文字。多角色、价值或场景页面应选择能帮助理解的主体，用相关插画、照片、关系图或有层次的图文分区，让对象与说明直接对应；不能只增加装饰填空。

现有素材不足且概念插画有帮助时，可使用当前环境的生图技能或工具，为当前主题生成匹配画风的插画。图片表达场景或机制，不补造真实现场、业绩或统计证据；标题、正文、数据与功能性图解继续保持可编辑。生成素材保存在项目工作区，不打包进通用 skill。

# 从参考提取视觉规则

只有用户提供或指定风格参考时才读取本流程。用户仅将文件作为内容来源时，不默认复制其视觉。没有参考文件也能使用本技能。

## 分离样式与项目

| 可以抽象复用 | 不自动继承 |
| --- | --- |
| 字体角色、字号比例和粗细对比 | 主题、标题、正文、姓名与机构 |
| 主色、正文色与强调色的分工 | 标识、联系方式、日期和文件信息 |
| 模块形态、轮廓、连接线与分组方式 | 原始图片、人物与具体场地 |
| 图片气质、裁切和图文主次 | 数据、业绩、案例和公式内容 |
| 对照、递进、汇合与反馈的空间组织 | 固定页数、页序或章节名 |

记录具体的文字层级、色彩角色、模块形状、箭头样式、图片语言、构图与密度节奏，不能只概括成“蓝白、简洁、专业”。去除身份和内容时保留可复用的视觉规则，在新主题中重新选择相关素材。

## 在预览阶段验证

文字稿确认后，先在 HTML 中设计适合该演示的代表性页面，例如封面、核心图解和图文页，内部对照参考，再完成全套预览。内部检查不增加新的确认门槛，也不能替代用户对完整预览的确认。

若差距来自字重、图形或图片，修正相应视觉规则，不同时改写已确认内容。保留参考的有效语言，不继承其拥挤、小字、无关身份或不清楚的连线。相近配色、图片数量或机械比例不能证明画风接近。

参考文件、截图、标识、项目素材和提取出的内容留在本次工作区，不能作为本技能依赖或打包资源。需要使用当前项目真实标识时，采用用户授权的正式文件并保持比例。
